Place public images in this folder. The current site shows styled placeholders until real images are added and wired in.

Recommended folder structure:

```text
public/images/
  hero/
    hero-01.jpg
  teacher/
    portrait-01.jpg
  classes/
    class-01.jpg
    class-02.jpg
    class-03.jpg
  private-sessions/
    session-01.jpg
  details/
    rope-detail-01.jpg
    fabric-detail-01.jpg
```

Recommended dimensions:

- Hero images: `2400 x 1600`
- Teacher portrait: `1200 x 1500`
- Class and session cards: `1600 x 1200`
- Detail images: `1600 x 1000`

Images in `public/images` are available at `/rope/images/image-name.jpg` after deployment to GitHub Pages.

For example, this file:

```text
public/images/hero/hero-01.jpg
```

is available at:

```text
/rope/images/hero/hero-01.jpg
```
